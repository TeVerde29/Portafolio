# Portafolio — Pedro Giovanni Ricra Figueroa

Portafolio profesional en HTML, CSS y JS puro. Sin frameworks, sin build.

## Ver en vivo

- GitHub Pages: https://teverde29.github.io/Portafolio/

## Estructura

```
Portafolio/
├── index.html   # contenido y secciones
├── styles.css   # diseño (tema claro/oscuro, responsive)
├── app.js       # cargador, consola, tema, menú, revelado, scrollspy
└── assets/
    └── foto.png # tu fotografía (ponla aquí con ese nombre)
```

## Foto de perfil

Guarda la foto que acompaña este encargo como `assets/foto.png` (recorte de rostro, fondo oscuro de preferencia).
Si el archivo no existe, el diseño muestra las iniciales `PR` como respaldo.

## Desarrollo local

Abre `index.html` en el navegador, o sirve la carpeta:

```powershell
python -m http.server 8080
# http://localhost:8080
```

## Despliegue

Rama `main`, carpeta raíz (`/`), vía GitHub Pages (tipo legacy).
Cualquier push a `main` se publica solo.
